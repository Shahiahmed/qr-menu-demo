# AGENTS

Полная инструкция по этому проекту — в [CLAUDE.md](CLAUDE.md). Прочитать её
**до** написания кода: там устройство приложения, схема данных, гостевой
Alpine-слой, админка Filament, деплой и найденные грабли.

Коротко, чтобы не ошибиться с самого начала:

- Это **не** основной SaaS из `../CLAUDE.md`. Здесь одноклиентское Laravel-
  приложение (Blade + Alpine + Filament) для одного заведения — без `tenant_id`,
  без Sanctum, без Next.js.
- Ассеты Vite **коммитятся** (`public/build`) — на сервере нет Node. Правил
  `resources/js` или `resources/css` → `npm run build && git add -f public/build`.
- Деньги — целые тиыны. Тексты — `*_ru` / `*_kk`. Строки гостевого UI — только
  в `config/guest.php`, обе локали.
- Тестов нет: проверять руками (браузер / `curl`).
- Секреты, адреса сервера и учётки — в `../demo-server-notes.md` (вне git).
